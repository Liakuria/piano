# Music → Piano V6 — Adaptive Piano Arrangement

スマホの画録・音声から、歌・ギター・ベース・ピアノ・ドラムを解析し、ピアノで弾きやすいMIDI / MusicXML / PDFへ変換するV6です。

## V6の強化
- 🎸 ギター→ピアノ：音符採譜＋コード推定＋左手伴奏
- 🎤 歌→ピアノ：主旋律を優先して右手へ
- 🎸 ベース→ピアノ：低音域を左手中心へ
- 🎹 ピアノ→ピアノ：原演奏をできるだけ保持
- 🥁 ドラム→簡易ピアノ打楽器リダクション
- 🎚️ 初級 / 中級 / 上級の自動音数制御
- 🎵 スタイル：自動 / ポップス / バラード / ワルツ / クラシック
- 🎹 伴奏：自動 / ブロックコード / 分散和音 / アルペジオ
- 🎤 主旋律優先モード
- ↕️ -12〜+12半音の移調
- 🖐️ 左手 / 右手の適応分割
- 🎼 コード推定・MusicXML
- 📄 LilyPond PDF

## 処理
動画/音声 → FFmpeg → 正規化 → Demucs → 対象楽器抽出 → HPSS → Basic Pitch → MIDI補正 → ピアノ化 → 難易度/スタイル別編曲 → コード伴奏 → 左右手分割 → MIDI / MusicXML / PDF

## デプロイ
- frontend: Vite + React / Vercel
- backend: FastAPI + Docker / Render

## 注意
Demucs標準4-stemはピアノとギターの完全独立分離を保証しません。複数楽器、強いリバーブ、歪み、複雑なポリフォニーでは推定誤差が出ます。V6の自動編曲も推定処理です。
